# Changelog

## 0.1.0 — 2026-11-12 (HKT)

- Added 10 explicitly synthetic FHIR-style fixtures and 4 self-authored demo safety rules.
- Added SQLite case state machine, persistent idempotency, deterministic four-read/one-draft
  tool loop and timestamped state/tool/card/decision event timeline.
- Added physician-role confirm/reject, unconfirmable block cards and access-driven expiry.
  MedicationRequest proposals remain draft after every decision.
- Added FastAPI endpoints, local HTML management pages, real-HTTP demo and fixture evaluation.
- Added package scaffolding, tests, lint, local Dockerfile and CI workflow file.
- Added English documentation, five README translations and automated consistency checks.
- Added Apache-2.0 license, notice, contribution, conduct and synthetic-data security policy.

This is a local repository milestone, not a published package or hosted deployment.
