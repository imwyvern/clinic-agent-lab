# clinic-agent-lab

Work in progress. P0 is under active development.

A Python laboratory for clinical *workflows*, physician confirmation gates, and reproducible safety evaluation. It uses **synthetic FHIR-style fixtures only**.

## Honest boundaries

- **Not a medical device.**
- **Not a diagnostic tool.** This project does not diagnose, treat, or recommend care for real patients.
- **Synthetic data only.** Fixtures are fictional. This repository is not a place to store real patient data or to train clinical models on real records.
- **No automatically executed orders** in the intended design. That behavior is still being implemented and tested.
- **Not a production system.**

## Status

This public snapshot is an early scaffold. Do not treat features as shipped until they are listed as shipped in this README and covered by tests. Documentation, evaluation, and the workflow demo are being added in subsequent commits.
